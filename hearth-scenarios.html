The same library, four different failures

These prices are the offline simulator for Gemini 2.5 Flash. They are not a provider bill. Regenerate this page with hearth scenarios --html hearth-scenarios.html.

A clock at the top of the instructions

The system text is the same every turn except the time. Observe and safe send that changing line first, so nothing is read from cache. Optimize moves the time onto the latest user message. The stable instructions are then read from cache and the input cost falls. The guard still records breaks, because the clock written onto an earlier turn is not in the history the next call sends.
